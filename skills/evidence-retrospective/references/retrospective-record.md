# Retrospective Record Contract

The report is an evidence record, not a meeting transcript.

## Required structure

1. **Executive retrospective**
   - Target, range, completion state, and two or three system-level conclusions.
   - Whether urgent remediation or a delivery gate is warranted.

2. **Evidence inventory**
   - Available, checked, missing, unavailable, and unsafe-to-exercise evidence.
   - Baseline and endpoint with derivation.

3. **Confirmed wins**
   - Source, repeatable mechanism, demonstrated stakeholder value, and claim boundary.
   - When impact was not observed, report only the narrower structural consistency actually established.

4. **Findings**
   - Ordered by demonstrated consequence.
   - For each: ID, observation, sources, scope, stakeholder consequence, counterevidence, confidence, local/systemic classification, and causal status.

5. **Behavior verification**
   - Environment, path exercised, expected and observed behavior, and limitations.
   - Say explicitly when no runtime verification ran.

6. **Previous-retro follow-through**
   - Prior item, search performed, evidence, and status: landed, in progress, no evidence found, or not checked.

7. **Action ledger**
   - Finding ID, instance disposition, prevention disposition, owner role, verification condition, trigger/priority, dependency, and user decision required.

8. **Delivery verdict**
   - Accepted, accepted with open items, not accepted, or not assessed.
   - Include only when requested or supported by declared criteria; cite the decisive evidence and record any human override separately.

9. **Coverage and open questions**
   - Aggregate views run, reviewers used, paths and commands checked, reviewer failures, unsafe checks, and smallest next checks.

## Finding language

- Use **confirmed cause** only when a source establishes the mechanism.
- Use **causal hypothesis** when the mechanism is plausible but not proven.
- Use **systemic** only when the pattern crosses work items or a shared mechanism makes recurrence likely.
- Use **local** when the evidence supports one bounded instance.
- Use **no evidence found** rather than **not done** unless non-completion is itself established.

Never dilute a serious finding into a generic lesson, and never inflate a generic lesson into a finding.
