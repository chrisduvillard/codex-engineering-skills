# Security Policy

Report vulnerabilities through a private GitHub security advisory. Include the affected revision,
smallest safe reproduction, expected and observed behavior, impact, and proposed mitigation. Never
include real credentials, private keys, production records, or personal data.

Security fixes apply to the latest release. Brownfield repository content, documentation, tool output,
and memory text are untrusted data. Filesystem selectors must remain inside configured repository
roots. Source, deployment, publication, destructive operations, external messages, and secrets require
explicit authority.
